## 📖 Tentang Proyek

**Rupiah Pintar** merupakan aplikasi multimedia interaktif berbasis web yang dikembangkan sebagai media pembelajaran edukatif untuk membantu anak Sekolah Dasar (SD) memahami konsep uang Rupiah melalui pendekatan **Learning by Doing**.

Aplikasi ini mengintegrasikan berbagai elemen multimedia seperti **teks, gambar, audio, animasi, video, dan interaktivitas** sehingga proses pembelajaran menjadi lebih menarik dan mudah dipahami.

Melalui simulasi nyata seperti mengenal uang, menukar pecahan uang, menjawab kuis, dan melakukan transaksi belanja, pengguna dapat belajar sambil bermain secara aktif.

# 🚨 Latar Belakang

Banyak anak usia sekolah dasar hanya mengenal nilai nominal uang melalui buku pelajaran, namun masih mengalami kesulitan dalam situasi nyata seperti:

* Membedakan detail fisik uang berdasarkan warna dan bentuk.
* Mengenali berbagai pecahan uang Rupiah.
* Melakukan penukaran uang ke pecahan lain.
* Menghitung total harga barang saat berbelanja.
* Memilih nominal uang yang sesuai untuk melakukan pembayaran.

Pembelajaran konvensional yang hanya berfokus pada teori sering kali membuat anak kesulitan memahami penerapan konsep uang dalam kehidupan sehari-hari.

---

# 💡 Solusi

Rupiah Pintar dikembangkan sebagai media pembelajaran interaktif yang menggabungkan:

* 🖼️ Visual (gambar uang Rupiah)
* 🔊 Audio (pengucapan nominal uang)
* 🎞️ Animasi interaktif
* 🎮 Gamifikasi edukatif
* 🛒 Simulasi transaksi belanja

Dengan pendekatan **Learning by Doing**, pengguna tidak hanya menghafal nilai uang tetapi juga mempraktikkan penggunaannya secara langsung.

---

# 🎯 Tujuan

* Membantu anak mengenal berbagai nominal uang Rupiah.
* Memahami karakteristik fisik uang.
* Melatih kemampuan berhitung sederhana.
* Melatih kemampuan menukar uang dengan pecahan yang berbeda.
* Memahami konsep pembayaran dalam kehidupan sehari-hari.
* Meningkatkan minat belajar melalui media multimedia interaktif.

# ✨ Fitur Utama

## 1. Mengenal Rupiah

Fitur pembelajaran dasar untuk mengenal uang Rupiah.

### Fungsi:

* Menampilkan berbagai nominal uang Rupiah.
* Menampilkan sisi depan dan belakang uang.
* Menampilkan warna dominan uang.
* Menampilkan informasi karakteristik uang.
* Audio pengucapan nominal uang.

### Tujuan:

Membantu anak mengenali bentuk dan nilai setiap pecahan uang.

---

## 2. Tukar Uang

Simulasi penukaran uang dengan berbagai kombinasi pecahan.

### Contoh:

```text
Rp50.000
=
5 x Rp10.000
```

### Fungsi:

* Menentukan kombinasi pecahan yang tepat.
* Melatih logika matematika sederhana.
* Memahami konsep kesetaraan nilai uang.

---

## 3. Kuis Rupiah

Permainan edukatif berbasis soal cerita.

### Fitur:

* ❤️ 3 Nyawa
* ⭐ Sistem Skor
* ⏱️ Timer 1 Menit
* Soal Acak

### Contoh Soal:

```text
Siti membeli 2 piring dan 3 mangkok.

Harga 1 piring = Rp3.000
Harga 1 mangkok = Rp4.000

Berapa total yang harus dibayar?
```

### Tujuan:

Melatih kemampuan berhitung dan pemahaman nilai uang.

---

## 4. Bayar Belanja

Simulasi kasir interaktif.

### Fungsi:

* Menampilkan total harga belanja.
* Memilih uang dari dompet digital.
* Melakukan pembayaran.
* Memahami penggunaan uang dalam transaksi nyata.

### Tujuan:

Mensimulasikan pengalaman berbelanja yang realistis bagi anak.

# 🔄 Metodologi Pengembangan

Pengembangan aplikasi mengikuti tahapan pembangunan Sistem Informasi Multimedia.

## 1. Analisis

Mengidentifikasi kebutuhan pengguna yaitu anak SD dalam memahami uang Rupiah melalui simulasi interaktif.

## 2. Perancangan

### Storyboard

Merancang alur navigasi dan interaksi pengguna.

### Desain Multimedia

Merancang:

* Tampilan antarmuka
* Aset gambar
* Audio
* Animasi

## 3. Implementasi

Mengintegrasikan seluruh elemen multimedia ke dalam aplikasi berbasis web.

## 4. Testing

Melakukan pengujian kualitas dan pengalaman pengguna menggunakan metode PLUME.

# 🚀 Instalasi

## Clone Repository

```bash
git clone https://github.com/username/rupiah-pintar.git
```

## Masuk ke Folder Project

```bash
cd rupiah-pintar
```

## Install Dependency

```bash
npm install
```

## Menjalankan Project

```bash
npm run dev
```

Buka browser:

```text
http://localhost:5173
```
